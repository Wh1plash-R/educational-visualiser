The Two Golden Heap Rules

1. Shape Property (Complete Binary Tree)

Every level is completely packed full, and the bottom row fills strictly from left to right without skipping any holes.

2. Order Property (Heap Order)

Max-Heap: Parent ≥ Children (Max is at the root).
Min-Heap: Parent ≤ Children (Min is at the root).

Up-Heapify (Bubble-Up)

Used strictly after INSERTING a new element

  1. Insert at the end: Place the new element at the very bottom right (maintaining Complete Binary Tree shape).
  2. Compare with Parent: Calculate parent index using ⌊k / 2⌋.
  3. Swap if Violated: In a Max-Heap, if new child > parent, swap them! (In Min-Heap: if new child < parent, swap).
  4. Repeat upward: Continue until the heap order property is restored or the node hits the root.
Handout Example Highlight: Inserting 40 under parent 20 violates Max-Heap (40 > 20). Swapping moves 40 up!

Down-Heapify (Bubble-Down)

Used strictly after EXTRACTING ROOT

  1. Extract root: Remove the root (highest priority item).
  2. Promote last leaf: Move the last leaf in the array to become the temporary root to preserve complete tree shape.
  3. Compare with children: Look at left (2k) and right (2k+1). Pick the larger child (Max-Heap) or smaller child (Min-Heap).
  4. Swap downward: If parent violates rule, swap with that child. Repeat until both children are valid or reaching a leaf.
Handout Example Highlight: Removing 50 puts leaf 15 at root. 15 swaps with larger child 40, then with 30.

Code Examples from Handout

Examine how Java's built-in PriorityQueue implements Heaps behind the scenes.

HeapExample.java (Exact handout implementation) 
import java.util.PriorityQueue; // importing PriorityQueue class
import java.util.Collections;

public class HeapExample {
    public static void main(String[] args) {
        // 1. Min-Heap: Natural ordering (smallest element at the head/root)
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        minHeap.add(30);
        minHeap.add(10);
        minHeap.add(20);

        System.out.println("Min-Heap (ascending order): ");
        while (!minHeap.isEmpty()) {
            System.out.print(minHeap.poll() + " "); // Output: 10 20 30
        }
        System.out.println("\n");

        // 2. Max-Heap: Reverse ordering (largest element at the head/root)
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        maxHeap.add(30);
        maxHeap.add(10);
        maxHeap.add(20);

        System.out.println("Max-Heap (descending order):");
        while (!maxHeap.isEmpty()) {
            System.out.print(maxHeap.poll() + " "); // Output: 30 20 10
        }
    }
}
💡 Key Takeaway: Notice that in both cases, numbers were inserted in order 30, 10, 20, but they are retrieved based on priority, NOT insertion order! 
// Array index calculation helper methods (1-indexed representation)
public class HeapHelpers {
    // If current node index is k:
    public static int parent(int k)     { return k / 2; }      // Integer division truncates!
    public static int leftChild(int k)  { return 2 * k; }      // Left child is always 2k
    public static int rightChild(int k) { return 2 * k + 1; }  // Right child is always 2k + 1

    // Quick verification example:
    // If k = 3:
    //   Parent      = 3 / 2     = 1  (Root)
    //   Left Child  = 2 * 3     = 6
    //   Right Child = 2 * 3 + 1 = 7
}
import heapq

# Python's heapq is a Min-Heap by default
pq = []
heapq.heappush(pq, 30)
heapq.heappush(pq, 10)
heapq.heappush(pq, 20)

print("Min-Heap dequeue order:")
while pq:
    print(heapq.heappop(pq), end=" ") # 10 20 30

# For a Max-Heap in Python, invert values by multiplying by -1
max_pq = []
for val in [30, 10, 20]:
    heapq.heappush(max_pq, -val)

print("\nMax-Heap dequeue order:")
while max_pq:
    print(-heapq.heappop(max_pq), end=" ") # 30 20 10
