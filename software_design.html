Creational Object Instantiation

Singleton Pattern

Ensure that a class has only one single instance, while providing a global access point to it.

💡 Layman Analogy

Think of the President of a country or the office coffee machine. There is strictly only one official president in office at any time. When citizens want decisions or declarations, they all refer to that single office, rather than electing new parallel presidents every single time a citizen has a question.

The Problem it Solves

If multiple components create their own separate connections to a single database or log file, they cause memory bloat and write conflicts. Global variables allow anyone to tamper with them unsafely.

The Architectural Solution

1. Hide the default constructor (make it private) so outsiders cannot use new.
2. Provide a public static getter (getInstance()) that creates the instance once and caches it for all future callers.

Essential Structure Components

Singleton Class: Contains a private static variable for the instance, a private constructor, and a public static method getInstance().
