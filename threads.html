📖 10 Lifecycle Rules from Handout (Harwani, 2015)

Click any rule to trigger that state transition on the diagram above.

Rule 1 • Unstarted

A new thread begins in Unstarted until Start() is called.

Rule 2 • Start() to Started

Start() moves thread to Started (Ready/Runnable) to await CPU time.

Rule 3 • Running State

Highest priority Started thread enters Running and executes instructions.

Rule 4 • Stopped & Abort

Task completion moves it to Stopped. Calling Abort() throws ThreadAbortException.

Rule 5 • Blocked (I/O)

Enters Blocked during I/O operations. Zero CPU time is wasted while waiting.

Rule 6 • I/O Resumption

When I/O completes, the thread returns to Started to resume CPU scheduling.

Rule 7 • WaitSleepJoin & Pulse

Enters sleep via Sleep(ms) or Wait(); another thread wakes it via Pulse().

Rule 8 • Sleep Expiration

When the millisecond timer expires, it returns automatically to the Started queue.

Rule 9 • Interrupt()

Can be abruptly awakened from WaitSleepJoin if another thread calls Interrupt().

Rule 10 • Join() Synchronization

If Thread A cannot proceed until Thread B completes, Thread A calls threadB.Join() and sleeps until Thread B terminates.

Multithreading, Race Conditions & Join()

In operating systems, multithreading allows multiple threads to run concurrently in a round-robin time-sliced fashion. When two child threads modify the same variable (x) at the same time, they compete in a Race Condition.

⚙️ Thread Properties

CurrentThread static Thread

Returns the specific thread instance that is currently executing this piece of code.

🍳 "Which chef is currently holding this spatula right now?"
IsAlive bool

Returns true if thread has started and not yet terminated or aborted.

🍳 "Is this cook still on duty in the restaurant?"
IsBackground bool

When true, the CLR will forcibly terminate this thread when all foreground threads finish.

🍳 Dishwashers who get sent home the moment the dining room closes.
Name string

Gets or sets the human-readable identifier for easy tracking and debugging.

🍳 The nametag worn on the chef's uniform.
Priority ThreadPriority

Hints to the OS scheduler which threads should receive more frequent CPU time slices.

🍳 VIP orders cooked first on the fastest burner.
ThreadState ThreadState

Bitwise flags indicating the exact stage (Unstarted, Running, WaitSleepJoin, Stopped, etc.).

🍳 The order status ticket (Prepping, Cooking, Resting, Served).

🛠️ Thread Methods

public void Start()

Transitions thread from Unstarted to Started, invoking the delegate callback method.

public static void Sleep(int ms)

Pauses the executing thread for the stated milliseconds, relinquishing CPU time to other threads.

public void Abort()

Terminates the thread by throwing a ThreadAbortException in its execution context.

public void Join()

Blocks the calling thread until this target thread finishes its complete execution.

public void Interrupt()

Interrupts a thread that is in WaitSleepJoin state, breaking its sleep immediately.

public static void ResetAbort()

Cancels an ongoing abort request inside the catch (ThreadAbortException) block.
