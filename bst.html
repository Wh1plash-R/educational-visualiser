DSA Traversal Exam Reviewer Cheat Sheet

Quick Recall Card
Inorder DFS

Left → Node → Right

  • Always yields sorted order on any BST.
  • Time: O(N)
  • Stack Space: O(H) (H = height)
Preorder DFS

Node → Left → Right

  • Visits root node immediately on entry.
  • Ideal for cloning or serializing trees.
  • Time: O(N) | Space: O(H)
Postorder DFS

Left → Right → Node

  • Processes children before parent (bottom-up).
  • Used for tree deletion and directory sizes.
  • Root node is recorded very last.
Levelorder BFS

Top → Down (Level by level)

  • Uses an iterative Queue (FIFO).
  • Dequeues from head, enqueues children to tail.
  • Space: O(W) (W = max width)
