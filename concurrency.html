Transaction Concept & ACID Properties

A transaction is a collection of operations that form a single logical unit of work. Even if a user views it as a single task (e.g. buying shoes, transferring money), the database executes multiple reads and writes. All must succeed, or all must be undone.

Deadlock Concept

A deadlock occurs when two transactions wait indefinitely for each other to unlock data. Follow steps 1 to 4 to trigger the deadlock condition and see how circular wait forms.

Active Technique Details:
  • Deadlock Prevention: Aborts a transaction if a deadlock could arise.
  • Deadlock Detection: Periodically checks for cycles in the WFG, selects a "victim" transaction, aborts and rolls it back.
  • Deadlock Avoidance: Transactions must obtain all locks upfront before executing.
